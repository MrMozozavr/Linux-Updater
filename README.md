Зручний Telegram-бот для віддаленого моніторингу та керування вашою системою на базі Linux. Отримуйте сповіщення про оновлення, переглядайте логи, оновлюйте систему та перезавантажуйте її прямо з вашого смартфона.

## ⚙️ Основні можливості

*   ✅ **Перевірка оновлень:** Автоматично при запуску та за командою.
*   🚀 **Оновлення системи:** Запуск повного оновлення системи однією кнопкою.
*   🔄 **Перезавантаження:** Безпечне перезавантаження системи після оновлення.
*   📄 **Отримання логів:** Можливість завантажити повний системний журнал або лише критичні помилки за поточне та попереднє завантаження.
*   🛡️ **Безпека:** Бот реагує лише на команди від авторизованого користувача (власника).
*   ⚙️ **Автозапуск:** Легке встановлення як системного сервісу `systemd`, що гарантує роботу бота у фоні та автозапуск після перезавантаження.
*   🐧 **Універсальність:** Автоматично визначає ваш дистрибутив (Arch, Debian, Ubuntu, Fedora та їх похідні) і використовує відповідний пакетний менеджер (`pacman`, `apt`, `dnf`).
*   🎯 **Ідеально для Debian/Ubuntu:** Використовує повністю неінтерактивний режим оновлення (`DEBIAN_FRONTEND=noninteractive apt-get`), що запобігає зависанню бота на запитах конфігурації.
*   📊 **Моніторинг портів та SSH:** Показує відкриті порти та дозволяє примусово зупиняти підозрілі сесії.

## 🐧 Підтримувані дистрибутиви

Бот автоматично визначає пакетний менеджер, тому він буде працювати на переважній більшості сучасних дистрибутивів, включаючи:
*   **Arch-based:** Arch Linux, Manjaro, EndeavourOS, CachyOS та інші.
*   **Debian-based:** Debian, Ubuntu, Linux Mint, Pop!_OS та інші.
*   **Fedora-based:** Fedora, CentOS, RHEL, Nobara та інші.

## 🚀 Встановлення

Встановлення максимально просте і повністю автоматизоване.

1.  **Клонуйте репозиторій:**
    ```bash
    git clone https://github.com/MrMozozavr/Linux-Updater.git
    cd Linux-Updater
    ```

2.  **Надайте права на виконання та запустіть інсталяційний скрипт:**
    ```bash
    bash install.sh
    ```
    Скрипт автоматично налаштує все необхідне: створить віртуальне середовище, встановить бібліотеки з `requirements.txt`, спитає у вас токен бота та ваш Telegram ID, і налаштує автозапуск. Пароль адміністратора (через `sudo`) буде запитано скриптом лише на етапі створення системного сервісу.

3.  **Готово!** Напишіть `/start` вашому боту в Telegram, щоб побачити головне меню.

---

## 🔧 Конфігурація

Під час встановлення скрипт `install.sh` автоматично створить файл `.env` з вашими налаштуваннями.

*   `TELEGRAM_API_TOKEN` — унікальний токен вашого бота, отриманий від [@BotFather](https://t.me/BotFather).
*   `ALLOWED_USER_ID` — ваш унікальний Telegram ID. Дізнатися його можна у бота [@userinfobot](https://t.me/userinfobot).

Якщо вам потрібно змінити ці параметри, просто відредагуйте файл `.env` та перезапустіть сервіс.

## ⚙️ Керування сервісом

Після встановлення бот працює як системний сервіс `systemd`. Ось основні команди для керування ним:

*   **Перевірити статус бота:**
    ```bash
    sudo systemctl status telegram-linux-monitor.service
    ```
*   **Переглянути логи бота в реальному часі:**
    ```bash
    sudo journalctl -u telegram-linux-monitor.service -f
    ```
*   **Перезапустити бота** (необхідно після внесення змін у код `linux_monitor_bot.py`):
    ```bash
    sudo systemctl restart telegram-linux-monitor.service
    ```
*   **Зупинити бота:**
    ```bash
    sudo systemctl stop telegram-linux-monitor.service
    ```

## 🗑️ Видалення

Для повного та чистого видалення бота з системи:

1.  Перейдіть у папку з проєктом.
2.  Запустіть скрипт видалення:
    ```bash
    sudo bash uninstall.sh
    ```
    *Скрипт зупинить сервіс, видалить його з автозапуску та видалить відповідний файл `systemd`.*
3.  Після цього ви можете безпечно видалити папку з проєктом:
    ```bash
    cd ..
    rm -rf Linux-Updater
    ```
